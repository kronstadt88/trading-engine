# 111 / 112 / 121 / 122

These are recurring structural families in the methodology.

Known working examples previously discussed:

- Gold: 111 example
- DAX: 121 example
- Thales: 121 example
- Natural Gas: 121 evolving into 122

A structure may evolve as new valid reactions appear. A 121 becoming a 122 should therefore be representable as **state evolution**, not necessarily as two unrelated patterns.

Required properties for any future detector:

- start/end points
- constituent legs
- reactions
- measured leg ratios
- tolerance used
- direction
- context
- confidence
- explicit reasons

The precise geometry must be calibrated against labelled examples.
