# Sota, Caballo and Rey

These are **operational concepts layered on top of the structural language**. They are not synonyms for 111/121/etc.

## Sota
A relevant level derived from prior structure.

It is not simply a generic support/resistance line.

## Caballo
The valid start / arranque associated with a Sota.

This is one of the first events the project should learn to detect reliably.

## Rey
The entry-level event found after descending to a lower timeframe and repeating the structural process.

Conceptual sequence:

higher timeframe structure
-> Sota
-> Caballo
-> descend timeframe
-> lower-timeframe structure
-> lower-timeframe Sota/Caballo
-> Rey

This makes the methodology intrinsically fractal and multi-timeframe.
