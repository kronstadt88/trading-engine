# Fractality and multi-timeframe structure

The same structural grammar can appear at multiple scales.

Example conceptual hierarchy:

1H: parent structure + Sota + Caballo
5m: child structure used to refine the entry
1m: optional further refinement

The engine must preserve explicit parent/child relationships between structures.

A lower-timeframe detector should not be treated as an unrelated scan. It is operating under context inherited from the higher timeframe.

The model should support:

- parent structure IDs
- child structure IDs
- timeframe hierarchy
- temporal containment / overlap
- inherited direction/context
- state transitions when descending timeframe
