# Overview

The purpose of this project is to formalize a discretionary market-reading methodology into a measurable, testable detection engine.

The first goal is **not profitability** and not automated execution. The first goal is to answer:

- Did the engine detect the same structure the human labelled?
- Where exactly did it detect it?
- Why?
- Which measurements supported the classification?
- Which false positives and false negatives remain?

Core concepts currently in scope:

- structural families 111, 112, 121, 122 and experimental 21X
- reactions
- absorption
- 180-degree rotation / structural symmetry
- Sota, Caballo and Rey
- starts / arranques, including front/back orientation
- fractal multi-timeframe relations
- evolution of a structure, for example 121 -> 122
