# Arranques / impulses: front and back

The methodology distinguishes at least two orientations of a valid start:

- por delante / front
- por detrás / back

This distinction must be part of the domain model and not collapsed into a generic breakout boolean.

An arranque/Caballo candidate should eventually expose:

- asset
- timeframe
- timestamp
- direction
- orientation: front/back
- start and end prices
- related Sota/level, if available
- structural context
- measured evidence
- reasons
- confidence

NEEDS_VISUAL_GROUND_TRUTH:
- exact geometric criterion separating front from back
- confirmation condition
- invalidation condition
- whether wick/close behaviour matters
